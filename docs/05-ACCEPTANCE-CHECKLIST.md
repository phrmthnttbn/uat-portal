# 05 — รายการทดลองรับมอบใน Browser

เอกสารนี้เป็นรายการให้ผู้รับมอบทดลอง ไม่ได้หมายความว่ารายการ UI ทั้งหมดถูกตรวจอัตโนมัติแล้ว ผลตรวจจริงอยู่ BUILD-VERIFICATION.md

## เตรียม

1. npm ci → npm test → npm run build → npm run dev
2. เปิด browser ที่อนุญาต localStorage และเปิดเพียงหนึ่ง tab ของ URL นี้
3. Backup ก่อน Reset Demo เพื่อไม่ให้กระทบข้อมูลที่ต้องเก็บ

## เมื่อพบปัญหา

บันทึก Project, ขั้นตอน, Expected, Actual และภาพหน้าจอ ถ้าเป็นข้อมูลสำคัญ Backup ก่อนเปลี่ยน state ส่ง error จาก Console หรือ Terminal โดยไม่ส่ง token/password
